% two-column-photo — narrow sidebar with an ID photo, wide main column.
%
% Trade-off, stated plainly: a photo and a two-column layout are conventional
% in Vietnam and fine for a person to read, but they are harder on automated
% CV parsers than ats-single-column. Use this where a human reads the CV
% first; use ats-single-column where it goes through an applicant portal.
%
% The two columns are minipages, so the sidebar's text is emitted before the
% main column's. Extraction therefore reads sidebar-then-main rather than
% interleaving the two, which is what keeps it parseable at all.
%
% Compiles with Tectonic using bundled resources only: TeX Gyre Heros loaded
% by file name, no system font required.
%
% Markers: PDFMETA in the preamble, SIDEBAR and BODY inside the document.
% Macro contract: see PLACEHOLDERS.md.
