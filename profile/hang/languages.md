# Languages

Spoken and written languages, one entry per language.

`certifications.md` records *which credential* proves a level; this file
records *the level you work at*, which is what a CV's Languages section prints.
When a certification backs the entry, name it in `Certification:` rather than
repeating the credential here.

- **Proficiency** is the short label: `Native`, `Advanced`, `Intermediate`,
  `Basic`. Do not invent a level a certification does not support.
- **Descriptor** is the parenthetical the CV prints after it. Keep it to what
  the profile can back.
